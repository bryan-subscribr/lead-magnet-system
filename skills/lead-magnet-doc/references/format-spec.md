# Format spec (cloned from Maria Wendt's lead magnet doc)

Source: Google Doc `1e-u1LtMoO9MYQN9whPFdrXH7lu-CHDNwUiWttowYYiw` ("8-Figures Business Working 2 Days A Week"). Its styles live in `assets/template.docx`, and `docbuilder.py` applies all of this for you.

| Element | Spec |
|---|---|
| Page | Letter, 1" margins, line spacing 1.15 |
| Title | Lora, about 30–40pt, centered, Title style. Use the user's headline exactly, never reworded |
| Subtitle | Lora 22pt, italic and underlined, centered, with **one word in blue** (#0000FF). Example: "And *Exactly* How To Build Yours" |
| Cover | An image collage under the subtitle (6-up grid or a hero image), 6.5" wide |
| TOC page | Its own page. "Table Of Contents" in Lora 28pt italic, centered. The entries are Google Docs' own TOC: Insert → Page elements → Table of contents → **2nd style (dotted leaders + page numbers)**. H1 entries are bold, H2 entries indented |
| H1 | Lora 20pt, not bold. One H1 per section, and sections run on without page breaks |
| H2 | Lora 16pt, not bold |
| Body | Arial 11. Paragraphs separated by an empty line. Group **2–3 related sentences per paragraph**, and only use single lines for a punch (Bryan's Second Brain bans one-sentence-paragraph spam) |
| Emphasis | Bold for the key line or number. Italic for quotes and prompts |
| Images | Full width (6–6.5") for grids and screenshots, 4–5" for single thumbnails. Captions are italic and in brackets: "(One thumbnail change. 40x the daily views.)" |
| Tables | Light grey borders (#BFBFBF), grey header row (#F3F3F3), bold header. Used for data, templates and "if X, use Y" tables |
| Lists | Numbered steps or plain bullets. Never bold-first bullets |
| CTA | The last H1, with one short paragraph and a bold "Go to" + link (Viral Bangers lead magnets → viralbangers.com) |

## Section heading rules (Bryan, 2026-10-06)
Headings say plainly what the section is, the way a person would say it out loud.
- Good: "TL;DR", "Who We Are", "Who Is RP Profits?", "Before Working With Us, Nobody Clicked His Thumbnails", "He Fixed The Design, But Nothing Happened", "Did It Work? Here Are The Numbers", "How To Build Your Thumbnail Formula (Step By Step)", "Want Us To Do This For You?"
- Bad: "The Short Version", "...And It Still Stalled" ("stalled" reads as AI), "Same Words. Wrong Package. 2,887 Views." (a clever stat-headline), "The Diagnosis", "Find Your Candlestick" (a jargon label)
